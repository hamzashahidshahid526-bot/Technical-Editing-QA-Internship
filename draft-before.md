# Bank Management System - User Guide (DRAFT)

## Introduction

This document has been written by the development team to explain the Bank management system. The system was created using C++ and file handling is utilized for data storage.

The System Should Be Used By The User To Manage Bank Accounts. The data is stored in a file called accounts.dat. 

It is recommended that the github repository should be downloaded by the user. After the download is completed, the code should be compiled by using g++.

The User Is Required To Click On The Run Button. Then, the account creation process will be started by the system.

## Features

The following Features Are Provided By The System:

*   The account creation functionality is provided.
*   Deleting an account can be done by the user.
*   The balance should be checked by entering the account number.
*   Money is transferred by the system from one account to another.

For file handling, fstream Library Is Used. The ifstream and ofstream classes are used for Reading and Writing. The Data Is Saved Using The Binary Mode.

The c++ code uses oops concepts. inheritance Is Used In The System. The base class is Account and Child classes are SavingsAccount and CurrentAccount.

The Internet connection is not needed by the system. It is designed to be run offline.

## How To Use The System

The Following Steps Should Be Followed By You:

1.  The main.cpp File Should Be Opened By You In Vs Code.
2.  The Program Should Be Compiled By You Using The Command g++ main.cpp -o bms.
3.  The bms.exe File Should Be Executed.
4.  The Option Should Be Selected By The User From The Menu.
5.  The Account Number Should Be Entered By You.

When the account number is entered, the details will be displayed by the system. If the account is not found, an error message will be shown by the system.

The Data Is Stored In The File. The File Should Not Be Deleted By The User. If The File Is Deleted, All The Data Will Be Lost.

## Installation Requirements

The following Requirements Are Needed:

*   vs code should be installed.
*   g++ compiler should be installed on the laptop.
*   100mb Ram Is Required.
*   windows 10 Or Higher Should Be Used.

The setup.exe file can be downloaded from the internet. The installation is completed by double clicking on it.
